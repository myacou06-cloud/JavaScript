Практичні завдання

Завдання 1: Ініціалізація ігрового поля

На цьому етапі потрібно отримати необхідні елементи з DOM та динамічно створити картки на ігровому полі.

  1. Створіть змінні для отримання елементів з HTML: сітки з id grid, лічильника кроків steps та лічильника збігів matches, використовуючи document.querySelector.
  2. Створіть функцію createBoard().
  3. Всередині функції пройдіться циклом (наприклад, forEach) по масиву cardsArray.
  4. Для кожного елемента масиву створити тег <img> за допомогою document.createElement.
  5. Встановіть створеному тегу атрибут src зі значенням змінної backImg.
  6. Встановіть атрибут data-id, який дорівнюватиме індексу поточного елемента в масиві.
  7. Додайте створений тег <img> всередину контейнера сітки.
  8. Викличте функцію createBoard() в самому кінці вашого JS файлу.

Схематичний результат:

На сторінці має з'явитися сітка 4х3 (12 карток) із зображенням "сорочки" (Покеболу).

Завдання 2: Логіка перевертання карток

Додамо інтерактивність — реакцію на клік гравця по картці.

  1. Створіть функцію flipCard(event).
  2. Поверніться до функції createBoard() і при створенні кожної картинки додайте їй прослуховувач подій: addEventListener('click', flipCard).
  3. В flipCard створіть умову: якщо змінна isBoardLocked дорівнює true АБО клік відбувся по тій самій картці, яка вже записана першою в масив chosenCardsElements — зупиніть виконання функції (return).
  4. Отримайте елемент, по якому клікнули (через event.target), та його атрибут data-id.
  5. Змініть атрибут src клікнутої картки на картинку відповідного покемона з масиву cardsArray (використовуйте отриманий data-id як індекс).
  6. Додайте клікнутий елемент у масив chosenCardsElements.
  7. Перевірте: якщо довжина масиву chosenCardsElements дорівнює 2, збільште stepsCount на 1, оновіть текст в HTML (лічильник кроків).

Схематичний результат:

При кліку на картку замість сорочки з'являється покемон. Після відкриття двох карток лічильник "Кроків:" змінюється на 1.

Завдання 3: Перевірка на збіг (Match)

Після відкриття двох карток гра повинна визначити, чи вони однакові, і відреагувати відповідно.

  1. Створіть функцію checkCards(). Викликайте її в кінці функції flipCard, якщо відкрито 2 картки.
  2. На початку checkCards() змініть isBoardLocked на true.
  3. Отримайте обидва елементи з масиву chosenCardsElements та їхні data-id.
  4. Якщо імена в cardsArray за цими id збігаються:
    • Змініть src обох карток на winImg.
    • Додайте обом карткам CSS клас matched.
    • Видаліть з обох карток прослуховувач подій кліку, щоб їх більше не можна було клікати.
    • Збільште matchesCount на 1 і оновіть на екрані "Знайдено: ... / 6".
    • Очистіть масив chosenCardsElements та розблокуйте дошку (isBoardLocked = false).
    • Якщо знайдено всі 6 пар — через setTimeout (500мс) виведіть alert з привітанням та кількістю кроків.
  5. Якщо імена різні:
    • Використайте setTimeout з затримкою в 1000мс.
    • Всередині таймера поверніть обом карткам атрибут src зі значенням backImg.
    • Очистіть масив chosenCardsElements та розблокуйте дошку.

Схематичний результат:

Якщо картинки різні — вони ховаються через 1 секунду. Якщо однакові — залишаються відкритими і стають напівпрозорими (завдяки класу .matched).

Завдання 4: Модальне вікно (Правила гри)

Створимо скрипт для управління модальним вікном, щоб гравці могли читати правила.

  1. Отримайте з DOM три елементи за їхніми id: модальне вікно (rules-modal), кнопку відкриття (rules-btn) та кнопку-хрестик (close-btn).
  2. Додайте слухач подій на кнопку "Правила гри". При кліку видаляйте з модального вікна клас hidden (через classList.remove).
  3. Додайте слухач подій на кнопку-хрестик. При кліку додавайте до модального вікна клас hidden (через classList.add).
  4. Додатково: Додайте слухач подій на саме модальне вікно. Якщо об'єкт, по якому клікнули (event.target), суворо дорівнює самому контейнеру модального вікна (темному фону, а не білому блоку всередині) — також додавайте клас hidden.

Схематичний результат:

При натисканні на кнопку з'являється спливаюче вікно, яке перекриває гру. Клік поза білим прямокутником (на темний фон) або на хрестик ховає його.
